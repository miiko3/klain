# klain

Нативный SwiftUI-клиент iOS 17+: локальная история чатов, потоковые ответы, загрузка моделей через `/models`, ручной ID модели, ключ в Keychain. Одно активное API-подключение. Без доступа к терминалу или управлению устройством.

## Сборка

В GitHub-репозитории нужны `Klain/`, `project.yml` и `.github/workflows/ios.yml`. Запусти Actions → Build klain → Run workflow. Скачай артефакт `klain-unsigned`: внутри неподписанная IPA. Для установки подпиши её через AltStore/SideStore или подходящую Apple signing-конфигурацию. Сборка не запускается автоматически и не требует API-ключей в GitHub.

На Mac: `brew install xcodegen`, затем `xcodegen generate` и открой `Klain.xcodeproj`. Для установки из Xcode выбери свою signing team.

## Использование

Открой «Модели», укажи HTTPS Base URL (например `https://openrouter.ai/api/v1` или `https://api.openai.com/v1`), ключ, загрузи модели и сохрани выбранную. Список моделей провайдера не гарантирует доступ к каждой из них. Прямой Anthropic Messages API пока не поддерживается; модели Claude доступны через совместимые шлюзы.

Вложения выбираются через «Файлы» (фото/видео можно предварительно сохранить туда). Изображения — vision API, UTF-8 файлы — текстом, PDF и видео — формат OpenRouter. Нужна поддержка конкретной моделью. Лимит 20 МБ на файл и 30 МБ на сообщение. Передаётся вся история выбранного чата, включая вложения; это влияет на стоимость запросов. История хранится локально в защищённом файле, ключ отдельно в Keychain.

## Статус

Первая реализация. На Windows нет Xcode: компиляцию и работу на устройстве необходимо проверить macOS workflow. Нет фонового выполнения, отмены генерации, удаления чатов и автоматического сокращения контекста. Для длительной генерации держи приложение открытым.
